# Create Performance Task

The Create Performance Task is a digital project completed during class for AP Computer Science Principles. In this project, I designed a program, recorded a demo of its implementation, and submitted written reflections on my code during the AP exam. 

## Tic-Tac-Toe
I chose to create my program based of of the game, which can be played between two humans or a human and computer. The computer makes pseudorandom moves, meaning that it will most likely lose, but it can beat you if you don't try.
